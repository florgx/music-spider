# 配乐网站爬虫项目

## 介绍

项目源于一次商业爬虫开发需求（抓取某配乐网站素材资源），商业项目完结后，基于个人兴趣与技术复盘，**独立复刻实现**了此版本。

虽然和原商业项目代码完全不同，但核心抓取逻辑（如资源定位、分页解析）与技术原理（分布式调度、反爬规避）保持一致，旨在沉淀可复用的 “轮子”，为后续类似资源抓取需求提供参考模板。

## 核心技术实现

### 1. 框架与分布式能力



*   基于 **Scrapy** 构建爬虫核心，天然支持模块化开发与请求异步调度；

*   集成 **Redis** 实现分布式协作与断点续爬：爬虫中断后重启，可自动读取上次未完成的任务队列，无需重新抓取已完成内容，大幅提升效率。

### 2. 反爬策略设计



*   **动态请求头**：通过自定义 `UserAgentList` 随机切换请求头，模拟不同浏览器 / 设备访问；

*   **自建代理池**：配置 Scrapy 自定义 `Middlewares`，启用自建代理池自动切换 IP。

### 3. 数据解析与处理



*   采用 **lxml.xpath** 精准解析 HTML 页面结构，定位配乐名称、风格标签、时长、下载链接等目标字段，大型项目时效率更高更稳定；

*   通过 `copy.deepcopy` 实现目标数据深拷贝，避免多线程 / 异步场景下的数据引用冲突，确保数据完整性。

### 4. 存储优化方案



*   基于 **os 模块**自动检测目录：程序启动时，根据配乐的 “风格 - 场景 - 情绪” 分类规则，自动创建多级存储文件夹（如 `./素材库/流行风格/适用场景/适用情绪/`）；

*   结构化存储素材：资源文件按分类路径保存，后续检索、管理素材更便捷。

## 环境依赖



1.  基础环境：Python 3.6+

2.  核心依赖库：



```
\# 安装依赖（建议使用虚拟环境）

pip install scrapy redis lxml
```



1.  第三方服务：需本地或服务器部署 **Redis**（用于断点续爬与分布式调度）。

## 使用说明



1.  **配置准备**：

*   修改项目根目录 `settings.py`，配置 Redis 连接信息（`REDIS_URL`）、代理池地址、目标网站域名等参数；

*   补充 `UserAgentList` 与代理池 IP 列表（路径：`middlewares.py`）。

1.  启动爬虫：



```
\# 进入项目根目录，启动分布式爬虫

scrapy crawl peiyue\py  
```



1.  查看结果：

*   抓取的配乐资源按 “风格 - 场景 - 情绪” 分类，存储于项目根目录 `./素材库/` 文件夹；

*   Redis 中会留存未完成任务队列，中断后重启爬虫即可续爬。

## 注意事项



1.  本项目仅用于 **个人技术学习与复盘**，抓取行为需遵守目标网站 `robots.txt` 协议与相关法律法规，禁止用于商业或违规用途；

2.  若目标网站更新页面结构（如 HTML 标签、分页规则），需同步修改 `spiders/` 目录下的解析逻辑（xpath 表达式、资源链接提取规则）；

3.  代理池需定期维护更新，避免使用失效 IP 导致爬虫效率下降或被封禁。
